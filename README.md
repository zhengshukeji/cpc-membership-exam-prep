# 入党考试复习

> 党史 · 厦门大学校史 · 党章知识点汇总，附 235 题题库与在线做题（自动判分 + 错题本）

## 在线访问

<https://cpc-membership-exam-prep.zhengshuyun.com>

## 使用方式

- **在线**：打开上面链接即可，手机浏览器同样可用
- **本地**：`index.html` 为单文件网页，下载后双击打开，零依赖、无需联网
- **打印**：页面已适配打印样式，可直接打印「知识点」部分当纸质资料

## 功能

- **知识点**：复习资料全文（时间轴、考点表格、易混对比、背诵模板），目录跳转
- **题库**：235 题（单选 / 多选 / 判断 / 填空 / 简答），按分组折叠，支持关键词搜索
- **做题**：自选范围、可选乱序，客观题自动判分并给解析，填空简答自评；错题本存于浏览器本地，支持只练错题

- 关键年份、数字与表述已对照权威来源核实（详见网页末尾「主要参考来源」）；网题库中个别过时答案已按现行党章修正，并在解析中注明。
- 原始复习资料见 `入党考试复习资料.md`。
