# 入党考试复习

> 入党考试复习资料：党史 · 厦门大学校史 · 党章知识点汇总，附 235 题题库与在线做题工具（单文件 HTML，自动判分 + 错题本）

## 在线访问

GitHub Pages 部署后访问：<https://zhengshuyuncom.github.io/20260918-party-membership-exam-review/>

> 若无法访问，先到仓库 **Settings → Pages** 确认已开启：Source = Deploy from a branch，Branch = main / (root)。

## 使用方式

- **在线**：直接打开上面的 Pages 链接，手机浏览器同样可用
- **本地**：下载 `index.html` 双击打开即可，零依赖、无需联网
- **打印**：页面已适配打印样式，可直接打印「知识点」部分当纸质资料

## 功能

| 模块 | 说明 |
|---|---|
| 知识点 | 复习资料全文（时间轴、考点表格、易混对比、背诵模板、考前一页纸），目录跳转 |
| 题库 | 235 题全部可查看，按分组折叠，支持题干/选项/答案关键词搜索 |
| 做题 | 自选范围或快捷组合，可选乱序；单选/多选/判断自动判分并给解析；填空/简答自评模式；交卷出成绩单与错题回顾；错题本累积在浏览器本地，支持只练错题 |
